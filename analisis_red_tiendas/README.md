Este proyecto aplica principios de **DevSecOps** y **ISO 27001 / DORA** al análisis de datos de una red de tiendas minoristas, utilizando **Python**, **Pandas**, **NumPy** y **Seaborn**.

---

## 🎯 Propósito
Desarrollado como parte del curso de UNIR, este notebook demuestra cómo integrar seguridad, calidad de datos y resiliencia operativa en procesos analíticos.  
El objetivo es identificar correlaciones entre **ventas**, **inventarios** y **satisfacción del cliente**, aplicando controles de integridad y validación de datos.

---

## 🧠 Habilidades demostradas
- Limpieza y validación de datos con Pandas (`dropna()`, `assert`)
- Cálculo de métricas con NumPy (mediana, desviación estándar, simulaciones)
- Visualización profesional con Seaborn y Matplotlib
- Manejo seguro de excepciones y control de errores
- Aplicación práctica de controles ISO 27001:
  - **A.12.6.1** Gestión de vulnerabilidades técnicas → validación de datos
  - **A.14.2.5** Ingeniería segura → diseño modular y separación de responsabilidades
  - **A.14.2.9** Pruebas de aceptación → manejo de excepciones y robustez
  - **A.9.4.1** Control de acceso → integridad de datos y prevención de manipulación
  - **A.16.1.5** Aprendizaje de incidentes → registro y mejora tras errores

---

## 📊 Análisis realizado
- Ingresos totales por tienda y producto  
- Promedio de ventas por categoría  
- Rotación de inventarios y detección de inventarios críticos  
- Relación entre satisfacción del cliente y rendimiento de ventas  
- Recomendaciones para tiendas con baja satisfacción
